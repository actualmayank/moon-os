# MoonOS 98 🌙

A polished retro operating-system portfolio — Windows 98-inspired desktop on desktop, Windows Phone-inspired tiles on mobile.

Built by [Mayank Kumar](https://actualmayank.github.io/).

## Tech

React · TypeScript · Vite · Tailwind CSS · Framer Motion · react-rnd

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173`

## Build

```bash
npm run build
npm run preview
```
